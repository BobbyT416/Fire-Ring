Fire Ring — Build 030

Changes:
- Affiliate/shop/reservation links now leave Fire Ring in a separate browser window/tab after a clear exit confirmation. Fire Ring itself remains open.
- Removed the old in-app partner-site behavior from all shopping/reservation actions.
- Added campground broadcast messaging concept to the Profile page.
- User can choose Current campground or Nearby campgrounds.
- Nearby range can be configured to 5, 10, or 25 miles.
- Added sample incoming campground broadcast with Reply to campers / Reply privately choices.
- Broadcasts do not create automatic replies or read receipts.
- Build 030 remains a front-end prototype; production messaging, authentication, age enforcement, moderation, blocking/reporting, and server-side location/visibility controls must be implemented securely on the backend.
