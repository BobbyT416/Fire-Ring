FIRE RING — BUILD 005
=====================

Major progress build.

1. Explore search:
   - Added a dedicated Search button.
   - Pressing ENTER in the search field performs the same search.
   - Results filter by campground/park name and PA region.
   - Clearing the field restores all results.

2. Real Pennsylvania campground seed directory:
   - Seeded 65 Pennsylvania State Park campground/camping entries from
     Pennsylvania DCNR's current "Where to Camp" listing.
   - Each entry includes region and published camping season.
   - Kentuck/Ohiopyle remains the rich interactive demonstration campground.

3. Navigation:
   - Search result opens a campground record.
   - Ohiopyle/Kentuck opens the full interactive campground experience.
   - Other real PA entries open a directory detail placeholder ready for enrichment.

4. Version:
   - Fire Ring • Build 005
